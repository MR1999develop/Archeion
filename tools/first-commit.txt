Initial version of Archeion: archive-based incremental backups

Archeion (ancient Greek for "archive") is a
Windows backup program in Rust and egui with Deja Dup's convenience and
Areca's archive model.

Workspace with four crates:
- core: profiles, archive names, manifests, path keys, merge planning,
  backup kinds, run event protocol (no I/O)
- engine: complete and incremental backups (one zip per file, plain
  copies or AES-256 zips with hidden names), free-space check and resume
  of interrupted backups, automatic merge by retention rules, manual
  merge and deletion of single backups, restore at any date, file
  versions, search, integrity check, destination lock and crash recovery
- scheduler: Windows Task Scheduler tasks for backup and merge
- app: egui 0.37 window with profiles, Backups and Activity tabs, run
  log; headless worker; English and Italian

Repository set up for GitHub: CI (fmt, clippy, tests on Windows),
release workflow building a portable zip from vX.Y.Z tags, Dependabot,
changelog and dual MIT / Apache-2.0 licence.

tools\check.bat passes: clippy clean, all tests green.
